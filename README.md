هذا المستودع هو نقطة البداية لمتابعة كورس **SQL من الصفر**. في هذا الفيديو يشرح **عمر الطاهر** لغة SQL للتعامل مع قواعد البيانات، ضمن مسار موجّه للمبتدئين ومهتمي تحليل البيانات.

## عن الكورس

تعلّم SQL يساعدك على قراءة البيانات وتنظيمها واستخراج المعلومات منها باستخدام الاستعلامات. ابدأ بمشاهدة الفيديو من البداية، وطبّق الأوامر بنفسك بالتوازي، ثم ارجع إلى الأجزاء التي تحتاج مراجعتها.

- **المستوى:** من المبتدئ إلى المتقدم
- **الموضوع:** SQL وقواعد البيانات
- **مناسب لـ:** المبتدئين، ومهتمي تحليل البيانات، وكل من يريد بناء أساس عملي في SQL
- **صيغة المحتوى:** فيديو تعليمي كامل على YouTube
- **اللغة:** العربية

## خطة التعلّم المقترحة

1. شاهد الدرس ودوّن المفاهيم والأوامر الجديدة.
2. طبّق كل استعلام بنفسك في بيئة قواعد بيانات مناسبة.
3. غيّر البيانات أو شروط الاستعلام، ولا تكتفِ بنسخ الأمثلة.
4. احتفظ باستعلاماتك وملاحظاتك في هذا المستودع للرجوع إليها.
5. بعد إنهاء الفيديو، أنشئ أسئلة أو تحليلات صغيرة على بيانات تجريبية لتثبيت ما تعلمته.

## المتطلبات

لا تحتاج إلى خبرة سابقة في SQL للبدء. ستحتاج إلى متابعة الفيديو، وبيئة تتيح لك كتابة وتشغيل استعلامات SQL حتى تطبّق بنفسك. يختلف الإعداد المناسب بحسب نظام قاعدة البيانات الذي تختاره.

## لمن هذا المستودع؟

- لمن يبدأ تعلم SQL للمرة الأولى.
- لمن يريد مراجعة أساسيات التعامل مع قواعد البيانات.
- لمهتمي تحليل البيانات الذين يريدون إضافة SQL إلى أدواتهم.
- لكل متعلّم يرغب في حفظ الملاحظات والاستعلامات والتمارين في مكان واحد.
